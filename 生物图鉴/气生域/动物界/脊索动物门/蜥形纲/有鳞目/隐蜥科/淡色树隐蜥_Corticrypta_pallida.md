# 淡色树隐蜥 *Corticrypta pallida*

## 基本信息

| 项目  | 内容                     |
| --- | ---------------------- |
| 中文名 | 淡色树隐蜥                  |
| 别名  | 灰伏兽                    |
| 学名  | *Corticrypta pallida*  |
| 分类  | 脊索动物门｜蜥形纲｜有鳞目｜隐蜥科      |
| 微生境 | 海拔-5km以上均有分布，常见于各类灰色树干 |
| 营养级 | 次级消费者，小型伏击捕食者          |

## 特征

- 具有带花纹的灰白保护色，静止时与浅色树皮融为一体
- 以黏性长舌捕捉小虫
- 能发出发出响亮的鸣叫声或咔哒声
- 有*C. obscura*（暗色）、*C. crepitans*（鸣叫）、*C. montana*（山地）等亚种

## 形态与生理

- 成体体长20cm左右，四肢较长，前后肢均具五趾，可相互握持，善于在树上攀爬，并有长尾。
- 舌尖上面有黏液，捕食时，舌头能迅速射出，黏住昆虫
- 表皮上有色素细胞，但只能调节黑色素分布

## 生态与习性

- 主要活动于林下和树冠较低处的灰白色树干，长时间保持静止，依靠保护色伏击经过的小型动物。
- 捕猎时通常等待猎物进入舌头的有效射程，再以弹射长舌迅速捕获；除更换伏击位置或受到惊扰外，很少进行长距离主动追逐。
- 连续的树木结构有利于其隐蔽和移动，开阔水面、长期淹水地带及缺乏大型植物的环境中较少见。

## 生物互作

- 一般捕食沿树干活动的小型群居虫类；捕猎时可能连同猎物携带的植物碎片一并吞入口中。
- 其保护色主要针对单色树皮形成的背景，使它既能接近猎物，也较难被更大型捕食者发现。

## 人文

- 减少果园害虫数量，通常被视为有益小兽。
- 可食用，介于鸡肉和蛙肉之间，但腥味重，微苦。腌制、风干后可以长期保存。
