# 低地角鹿 *Cornucervus scalaris*

## 基本信息

| 项目  | 内容                             |
| --- | ------------------------------ |
| 中文名 | 低地角鹿                           |
| 别名  | 饰角鹿，冠鹿                         |
| 学名  | *Cornucervus scalaris*         |
| 分类  | 动物界｜脊索动物门｜哺乳纲｜偶蹄目｜鹿科           |
| 微生境 | `-0.5～-3.5 km` 的阶梯山地，林窗、断崖缓坡等地 |
| 营养级 | 初级消费者                          |

## 特征

- 雄性肩高约0.8米，雌性较小，躯干紧凑，四肢短而强壮，足趾可向两侧张开。
- 鹿角长而多叉，角枝内弯，可以压低或扯落灌木枝条，以取得嫩叶、花与果实。
- 不擅长长距离高速奔跑

## 形态与生理

- 蹄垫宽以减小压强，边缘硬角质提供额外的攀援能力
- 具有可短时闭合的外鼻瓣，可以在雾潮期间短暂活动。
- 肠道共生体可处理苔藓、嫩枝和纤维果皮，但需要定期摄取富矿物盐。

## 生态与习性

- 小群沿固定路线随季节在各个海拔带间往返。
- 食性丰富，包含各类植物和少量真菌类。
- 繁殖季雄性出现仪式化的**饰角行为**，将藤蔓、枝叶及花序缠绕在鹿角上，并携带植物进行求偶、展示

## 生物互作

- 是连接 `-1 km` 宜居带与 `-2～-3 km` 云雾林的主要种子传播者。
- 幼体和病弱个体是林间大型捕食者目标

## 人文

- 性情较温和，可以驯化，人工繁育。主要作为肉畜，鹿角则多用于贸易。
- 可食用。肉质细、纤维短，颜色深红，脂肪含量低。里脊、背脊、后腿常用于煎烤，肩颈，腹部则多用于炖煮。也有用血液、碎肉、小肠制成的血肠，但在低地人联盟不受欢迎。
- 发情期雄鹿的饰角，是订婚的礼物。这也为其野外种群的存续带来了一定挑战。

## 来源依据

- 现实原型：麂、鹿、岩羊、山地有蹄类季节迁徙
