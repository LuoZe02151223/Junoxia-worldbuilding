# 深谷巫师：法器

## 总述

法器是深谷巫师介入自然的工具，法器一般分为三类：**火钵、法杖、法袍**。

| 法器  | 职能          |
| --- | ----------- |
| 火钵  | 制造初始扰动      |
| 法杖  | 定向感知，引导扰动传播 |
| 法袍  | 全向感知，分担施法负荷 |

火钵提供初始扰动，法杖与法袍则用于扩大感知范围、引导扰动传播。法器的效用以巫师对自然规律的理解和环境条件为上限——环境越适合某种变化，施法越省力；环境偏离目标越远，过程越难维持，法器也越容易受损。

法杖与法袍一般具有活性：代谢、生长，疲劳、死亡，并对环境变化与施法负荷作出反应。因此，对巫师而言法器近似于他们的共生器官，法器的养护技巧是巫师训练的关键内容。

## 二、火钵

火钵是深谷巫师常用的**扰动源**。深谷潮湿多雨、明火难存，火钵将篝火缩小为可携带施法热源，承担保火、起势的职能：保存炭火，提供稳定可控的热量，利用热空气制造局部压差。通过更换燃料、调节进气、投放助燃粉末、移动钵体等方法，巫师能够调控热量释放的速度以产生合适的扰动。

火钵的养护以干燥、畅通为要点：定期清理积灰与焦油，保持进气孔通畅；检查钵体与隔热层的完整；燃料的防潮处理；长途旅行时应定期检查火种。

但，火势太小时，扰动难以被放大；火势过强，则可能形成乱流，灼伤法杖、法袍甚至巫师自己。

## 三、法杖

法杖是深谷巫师的**探针与指挥棒**，将巫师的感知集中到某一方向，也用于引导级联反应的方向，为法术提供明确指向。
法杖由**杖身**与**杖端**构成。杖身由保有活性的木质组织培育、修整而成，其上种植、嫁接各类真菌，共同承担传导与感知，杖尾处常保留根系以方便养护。杖端则取自天帆遗体中的活性结核，是法杖难以替代的部位。活性结核对大气过程异常敏锐，能将细微变化传递给施术者。

法杖在使用中持续生长。巫师通过修枝、嫁接等方法调整其形态，并在长期共处中熟悉它的反应方式；同一根法杖在不同巫师手中表现各异，差异主要来自长期使用与养护形成的适应。学徒雕刻杖身，就是在塑造自己的共生器官。

日常养护包括定期补水，给予适度光照，清除腐烂组织，并对裂口进行封护。施法负荷过大时，杖身会出现软化甚至坏死，杖端也会出现裂痕、失活，部分变化是不可逆的。

## 四、法袍

法袍是披覆于巫师身体外的**活性表皮**：风巢木的光合纤维、苔藓、菌丝等等，被长期培育并缝合在柔性基底上。

法袍可以在法杖的定向判断的基础上持续提供环境背景场。此外，法袍可以隔绝有害环境，提供一定的防御能力；其活体表层还能打散人的轮廓，使巫师融入林地。各类组织各司其职：光合纤维感知风速、风向，也分泌矿质使法袍硬化；苔藓感知温度湿度，菌丝传递化学刺激。这些复合纤维通过开合的程度来控制背景感知的深度，并形成近似阵列的效果。法袍将巫师的身体边界向外扩展，以维持向第一自然“开窗”的状态。

日常养护要求保持适度的湿度，光照，清理坏死组织，并补充必要的养分，定期梳理纤维，防止黏连。高负荷施法之后必须提供足够的恢复期。
修补时，普通布料部分可以缝合，活体表层则需移栽或重新播种。局部死亡会留下感知盲区，以布片补齐外观之后，法器功能仍待活体组织重新长成方可恢复。

## 五、工作流

1. **观察**：判断当前可利用的自然条件；
2. **供能**：点燃火钵，建立稳定热源；
3. **开窗**：将意识向自然敞开；
4. **选定路径**：集中感知某一方向；
5. **制造扰动**：调整火钵，使局部环境偏离原有平衡；
6. **引导放大**：法杖修正方向，法袍监测整体反馈；
7. **恢复养护**：处理火钵，为法杖与法袍补水、检查并静置。

## 六、视觉

### 火钵

较小，可单手提携或悬挂，外形近似有盖的陶罐、香炉或小型熔炉；外侧配金属箍、绳带与隔热结构，表面因烟灰、树脂与长期使用形成深色包浆。

### 法杖

杖身细长、略带弯曲，保留活木生长形成的结节，表面可见藤蔓、苔藓、菌类附生；杖端呈温润而半透明的质感；杖尾垂落根须或纤维。整体兼具工具、植物与感官器官三重特征。

### 法袍

轮廓宽大、厚重、不对称，由布、植物纤维层层叠合；苔藓、地衣、与绒毛沿肩背、袖缘与下摆密集生长，边缘呈破碎状与披挂状。静止时形似林地的一部分，施法时表面纤维依次竖立、倒伏或颤动。
